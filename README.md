# Reqnroll Automation Framework

A scalable BDD automation testing framework built with Selenium WebDriver, Reqnroll, C#, NUnit, and Page Object Model (POM).

## 📌 Tools & Technologies
- C#
- Selenium WebDriver
- Reqnroll
- NUnit
- Visual Studio

## 🚀 Features
- BDD based test automation
- Page Object Model (POM) design
- Reusable step definitions
- Easy maintenance and scalability
- Automated test execution with NUnit

## 📂 Project Structure
- Features
- StepDefinitions
- Pages
- Hooks
- Utilities

## ▶️ How to Run
1. Open solution file in Visual Studio
2. Restore NuGet packages
3. Build project
4. Run tests using Test Explorer
